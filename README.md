## 八、几个常见问题

**Q1：年付到期后续费还是这个价吗？**

恒创科技的促销活动明确写"续费同价"，也就是说年付到期后按下单时的年付价续费，不会涨回原价。这是它和很多国内商家不同的一点，也是它年付折扣看起来比同行更激进的原因——不是首年低价第二年涨价那种套路。

**Q2：CN2 GIA 和优化回国线路有什么实际区别？**

CN2 GIA 是中国电信的精品直连线路，走 59.43 段 AS4809 节点，国内三网回程都走 CN2 GIA，丢包率低、晚高峰不容易拥堵。优化回国线路一般是 CN2 GT 或 BGP 多线优化，平时延迟能压到 30-50ms，但晚高峰或节假日可能波动。两者在白天的体感差距不大，晚高峰差距会比较明显。如果你做的是面向国内用户的业务，建议优先 CN2 GIA。

**Q3：50M 和 100M 大带宽实际能跑满吗？**

大带宽套餐标的是独享带宽，理论上限速就是 50M 或 100M。但实际能不能跑满还取决于你本地的国际出口带宽、运营商国际出口拥塞情况，以及目标服务器到国内中间链路的状态。香港节点到国内走优化回国线路，白天通常能跑到标称带宽的 80% 以上，晚高峰可能下滑到 60-70%。如果你对带宽稳定性要求很高，建议先按月付试一个月，确认实际表现再切年付。

**Q4：1 个独立 IP 够用吗？**

所有套餐默认带 1 个独立 IPv4，对于建站、远程办公这种场景够用。如果你要做站群、需要多 IP 段，云服务器套餐不直接支持，得转去看恒创的站群独立服务器（126-254 个独立 IP，按 1C/2C 段划分），那已经是另一个产品线了。

**Q5：支持哪些付款方式？**

支付宝、PayPal 美元支付、银行在线转账、银行线下转账。国内用户用支付宝最方便，海外用户可以用 PayPal。
